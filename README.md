# Hi, I'm Inbasekaran 👋

I'm a software engineer at RingCentral. I work on AI features and backend systems. I also enjoy working on open source and exploring how things work under the hood.

## What I've been working on

- **Smart Filters:** Built a way to filter calls using natural language, so users can describe what they're looking for instead of picking filters one by one.
- **ACE MCP:** Designed a query language for accessing and analyzing conversation data through MCP. I also worked on evaluations for conversations that need multiple tool calls.
- **AI-native engineering:** Built tools and workflows that help my team use AI for planning, coding, and debugging.
- **Backend engineering:** Worked on analytics backends, Elasticsearch performance, and multilingual search.

## Open source

- **LFX Mentorship:** Added mathematical functions and tests to [SoftPosit C++](https://github.com/Posit-Foundation/soft-posit-cpp/commits/refactor-cpp-soft-posits?author=the-pinbo) to support work on posit arithmetic.
- **Google Summer of Code:** Built [VisionGuard](https://github.com/inbasperu/VisionGuard), an on-device gaze tracking app, with the Intel OpenVINO community. [Project page](https://summerofcode.withgoogle.com/archive/2024/projects/QUbIeRAM) · [Write-up](https://medium.com/openvino-toolkit/visionguard-ai-eye-care-for-computer-users-d055a574d8e9)
